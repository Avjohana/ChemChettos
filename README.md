# ChemChettos
Un sistema IA ya que los bancos no pueden distinguir si quien llama es humano o una IA que clonó su voz. ChemHack lo hace con tres señales: cómo suena la voz, cómo reacciona en la conversación y qué dice cuando le preguntas algo que no existe. Todo en un endpoint que responde en segundos. Es la diferencia entre confiar en una voz o verificarla.
